types.MapBuilder

types.MapBuilder(
    regions=None,
    *,
    tooltips=None,
    view_box=None,
    _outline=None,
    _resolved_aes=None,
    _mode=None,
)

Fluent builder for constructing map payloads with method chaining.

Parameters can be provided here or via output_map(). When both are provided, builder parameters take precedence.

Example (traditional): @render_map def my_map(): return ( Map(outline, tooltips=tooltips, view_box=viewbox) .with_value(my_counts) )

Example (with static params in output_map()): # UI layer output_map(“my_map”, outline, tooltips=TOOLTIPS, view_box=VIEWBOX)

# Server layer
@render_map
def my_map():
    return Map().with_value(my_counts)

with_fill_color

types.MapBuilder.with_fill_color(fill_color)

Color regions by ID, e.g. with the output of aes.color.scale_sequential.

Each entry becomes aes.Shape(fill_color=...) for that region, layered over any aes already set: other properties of the region are kept.

Parameters

Name Type Description Default
fill_color Mapping[str, str] Mapping of region ID to color. required

Examples

@render_map
def my_map():
    colors = scale_sequential(counts, region_ids, max_count=5)
    return Map().with_value(counts).with_fill_color(colors)

with_value

types.MapBuilder.with_value(value)

Set region values (counts, selection state).

Values determine both visual state and selection: - value = 0: not selected (base aesthetic) - value > 0: selected (select aesthetic applied)

Integer-like values (e.g. numpy ints from pandas) are converted to int.
