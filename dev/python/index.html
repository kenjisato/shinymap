Python API Reference

Core Components

Main UI components for creating interactive maps

input_map
output_map
render_map
update_map Update an input_map or output_map without full re-render.
Map Create map from Outline object.
types.MapBuilder Fluent builder for constructing map payloads with method chaining.
Outline Canonical outline representation with polymorphic elements.
Wash Create configured map functions with custom default aesthetics.
default_wash The look every map gets unless you make your own Wash.

Selection Modes

Mode classes controlling selection behavior

mode.Single Single selection mode with customization options.
mode.Multiple Multiple selection mode with customization options.
mode.Cycle Cycle mode - finite state cycling (e.g., traffic light survey).
mode.Count Count mode - unbounded counting.
mode.Display Display-only mode for output_map.

Aesthetics

Classes for styling map regions

aes.Shape Create shape aesthetic (fill and stroke).
aes.Line Create line aesthetic (stroke only, no fill).
aes.ByState Container for element aesthetics across interaction states.
aes.ByGroup Container for aesthetics by group/region name.
aes.Indexed Create indexed aesthetic for multi-state modes (Cycle, Count).

Color Scales

Functions for generating fill colors

aes.color.scale_sequential Create a sequential color scale based on counts.
aes.color.scale_continuous Color data values (populations, ratios, …) along a sequential palette.
aes.color.scale_diverging Create a diverging color scale (red-white-blue style).
aes.color.scale_qualitative Create a qualitative color scale for categorical data.

Relative Expressions

PARENT proxy for relative aesthetic values

PARENT
RelativeExpr A deferred expression that references a parent property.
resolve_region Resolve the final aesthetic for a region given its state.
preview_region Preview the aesthetic resolution for a region with verbose output.

Outline Utilities

Tools for working with SVG outlines

outline.Regions Dictionary subclass with clean repr for region data.
outline.export_svg Export shinymap outline to SVG file.

SVG Elements

Element classes that make up an outline

svg.Circle Circle element with bounds calculation and JSON serialization.
svg.Ellipse Ellipse element with bounds calculation and JSON serialization.
svg.Line Line element with bounds calculation and JSON serialization.
svg.Path Path element with bounds calculation and JSON serialization.
svg.Polygon Polygon element with bounds calculation and JSON serialization.
svg.Rect Rectangle element with bounds calculation and JSON serialization.
svg.Text Text element with bounds calculation and JSON serialization.
svg.is_stroke_only_candidate Detect if elements are likely intended as lines rather than filled shapes.

Static Analysis and Export

Inspect resolved aesthetics and export static SVG without a Shiny session

StillLife Static snapshot of a map for aesthetic analysis and SVG export.

Kit: Preparing SVG Files

Programmatic counterparts of the sketch app (python -m shinymap.kit.sketch)

kit.convert Convert SVG or JSON file to shinymap JSON format.
kit.apply_mapping Apply a mapping dict to convert an outline.
kit.generate_code Generate Python code for the conversion.
kit.describe Generate Text elements with region IDs at each region’s center.
kit.glaze Add regions as overlay (default) or underlay to an existing outline.
